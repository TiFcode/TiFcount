# TiFcount

Un joc de numărat pentru copii: numără bulinele din stânga și alege cifra corectă dintre cele trei opțiuni din dreapta.

- Răspuns corect: artificii, mesaj verde și o fanfară veselă.
- Răspuns greșit: mesaj roșu și un sunet scurt de eroare.
- Fiecare rundă are bulinele și cifrele rearanjate aleatoriu.
- Contorul de răspunsuri corecte și greșite rămâne vizibil sus.
